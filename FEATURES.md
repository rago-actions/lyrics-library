## 🎯 User Workflows

### New User Journey
1. 🌐 **Visit site** → See 129 songs
2. 🔍 **Search** → Find desired song
3. **Click card** → View full lyrics
4. ⭐ **Star favorite** → Save for later
5. 📤 **Share** → Send to friends

### Power User Journey
1. ⌨️ **Press `/`** → Focus search instantly
2. 🔤 **Type query** → Fuzzy search finds matches
3. ↵ **Press Enter** → Open first result
4. 🔤 **Ctrl +/-** → Adjust font size
5. 📋 **Copy** → Share lyrics
6. ⭐ **Press F** → Toggle favorite
7. 🚫 **Press Esc** → Close card

### Mobile User Journey
1. 📱 **Visit on phone** → Responsive layout
2. 👆 **Tap card** → Full screen lyrics
3. 📏 **Pinch zoom** → Adjust text size
4. ⬇️ **Swipe down** → Close lyrics
5. ⭐ **Tap star** → Save favorite
6. 📤 **Share** → WhatsApp friends

## 📈 Performance

- All songs load in one request (`songs.json`, ~300 KB uncompressed) instead of one request per song
- After the first visit the site works offline (service worker)
- Search runs client-side over title, lyrics and type

## 🔒 Privacy & Security

### Data Collection
- ❌ No analytics tracking
- ❌ No cookies
- ❌ No user accounts
- ✅ No external requests: fonts are self-hosted (`fonts/`) and cached by the service worker
- ✅ Only localStorage (local only)

### Data Storage
| Data Type | Storage | Shared |
|-----------|---------|--------|
| Favorites | localStorage | No |
| Recents | localStorage | No |
| Theme | localStorage | No |
| Font Size | localStorage | No |
| All other | None | No |
