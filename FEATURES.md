# Features

## Finding songs
- Search by title or lyrics; spelling variants match (yesayya / yesayyaa)
- Filter by first letter, favorites, or recently viewed
- Sort A → Z or Z → A

## Reading
- Click a card to open the lyrics; previous/next buttons move between songs
- Show or hide the English transliteration
- Font size controls
- Presenter mode: full screen, large text (`P`)

## Sharing
- Copy a song link, share to WhatsApp, copy the lyrics, or print
- Every song has its own page and a direct link (`?song=...`)

## Look and feel
- Dark and light themes
- Five colour palettes: gold, sapphire, emerald, rose, violet
- "Featured today" carousel that rotates automatically
- Floating menu with All, Favorites, Recent, sort, palette, theme, help

## Keyboard shortcuts
| Key | Action |
|-----|--------|
| `/` | Focus search |
| `Esc` | Close card or dialog |
| `← →` | Previous / next song |
| `P` | Presenter mode |
| `F` | Toggle favorite |
| `Ctrl +` / `Ctrl -` | Font size |
| `?` | Show shortcuts |

## Other
- Works offline and can be installed as an app
- Screen reader and keyboard friendly
- Preferences stay in your browser; no tracking, no accounts
